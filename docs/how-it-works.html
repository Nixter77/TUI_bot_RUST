03 Главный цикл TUI — что происходит каждые 200 мс

Ключи не ждут REST. Снимок живёт в потоке snapshot-poll. Live HTTP — try_lock на клиенте: если поллер уже держит mutex, тик пропускает apply и идёт дальше.

BOOT
Если live — acquire_live_lock(.state/live.lock). Чужой живой pid → exit 2 (AlreadyExists). Свой pid тоже не ворует замок. Journal + errorlog. seed_cooldowns из trades.jsonl. Первый REST до raw-mode, чтобы Ctrl+C ещё был SIGINT. Live: сразу reconcile_live, при грязи — второй pull.
SPAWN
SnapshotPoller каждые 5 с (или bump() по r / flatten): tradfi_symbols → fetch_snapshot → слот latest. catch_unwind: паника потока не убивает процесс, счётчик take_panics() → футер «сеть: поток снимка упал».
TICK
poller.take() есть? Тогда tick_once (чистый CPU) → paint кадра → apply_live_once (reconcile + apply каждого Decision). Если снимка нет 30 с — stale warning, не «всё хорошо».
KEYS
1234 стратегия (без HTTP). r снять entries_paused, очистить last_error, bump poller. x затем x flatten всех (и unmanaged shorts). Любая другая клавиша снимает arm. q / Esc / Ctrl+C — restore terminal, stop poller, drop lock.
PAINT
terminal::size().unwrap_or((80,24)) — ioctl в SSH/tmux не валит процесс. Цвета: зелёный PnL / красный убыток / жёлтый warn. line_tone смотрит «нетто=», «день:», «до входа:».

04 Снимок рынка. Что лежит в MarketSnapshot

Публичное (без ключей)

  • tickers — 24h tape, парсится только ^[A-Z0-9]{2,20}USDT$, junk/1000x выкинут
  • bars / universe_bars — рабочие klines выбранного TF
  • htf_bars — 4h для S4 EMA20
  • last_bars — последний закрытый бар книги (S1: 5м; S4: STRATEGY4_INTERVAL)
  • chart_symbol — что рисует панель графика

Приватное (ключи)

  • account wallet / uPnL / available. Equity = wallet + uPnL, не available
  • account_ok / account_fresh — 502 не обнуляет книгу: берётся prior
  • live_book + open_positions из positionRisk
  • overlay SL/TP: RAM state ⊕ journal unmatched opens (partial close не возвращает старый стоп)
  • ticker 24h упал → вернуть prior tickers, не пустую ленту

S4 klines книги фетчатся с каденсом SCAN_SEC=60. Между сканами monitor/watch переиспользует prior, чтобы не молотить REST каждые 5 с. Live не двигает last_scan_ts в snapshot — это делает continuation_decisions после maybe_enter.

06 Стратегия 1 — Momentum rider

Книга входа

  • Ранг 24h % среди tradable USDT-M
  • Мин. рост +0.4%, потолок +12%
  • Мин. quote volume 50k, junk/1000x/TradFi out
  • Слотов: STRATEGY1_MAX_POSITIONS (1–10)
  • Окна UTC 00–02 / 07–10 / 13–16, либо STRATEGY1_ALWAYS_ENTER=1
  • Poll 60 или 120 с

Сетап и выход

  • s1_setup_skip: не в топе / у 24h high (2%) / нет 5м / 5м красная
  • TP net +2.5% (после комиссии), trail 2.0% только вверх
  • Выпал из топа → Exit «выпал из топа — закрываю до стопа»
  • Красная 5м на открытом → Exit до стопа
  • Любой открытый слот в минусе → новый EnterLong запрещён («слот в минусе»)
  • Mark ≥ TP / mark ≤ SL → Exit

Размер: ORDER_NOTIONAL_USDT (не RISK_PCT). Это не академический weekly momentum. Это 24h-gain book + фиксированные %.

10 S4 ведение позиции — машина состояний

manage_continuation_long вызывается на каждый тик по каждому лонгу, независимо от SCAN_SEC. Входы ждут 60 с; стопы — нет.

A. До 1R (SL < entry)

  • Mark ≥ TP → Exit take profit
  • Mark ≤ SL → Exit stop
  • 4h close ≤ EMA20 → «4ч сломал тренд»
  • Удержание ≥ 4 ч с opened_bar_time → «тайм-стоп 4ч»
  • Конец окна (если не ALWAYS_ENTER) → Exit «конец окна входа»
  • Пик ≥ 0.8R и откат < 0.25R → замок 0.25R, иначе Exit «откат с пика»
  • Иначе hold «жду 1R»

B. Удар 1R

  • Если ещё не scaled_one_r: ReduceLong ≈ 50% qty, SL остатка = entry × (1+0.08%)
  • Лот неделим → только AmendStop BE, latch всё равно ставится
  • Дальше: mark/peak ≥ 1.5R → Exit «1.5R — фиксирую»
  • Иначе BE-amend; если BE невалиден → Exit «1R был — фиксирую»

C. После BE (SL ≥ entry)

  • Mark ≥ 1.5R → Exit
  • Peak был 1.5R, mark ещё жив → замок 0.5R
  • Trail: candidate = max(low сигнального бара, mark×(1−trail_pct 0.8%)), только вверх, long_stop_is_valid

Latch scaled_one_r живёт в RAM. Рестарт: journal overlay хранит остаток после partial close, чтобы не вернуть до-1R стоп и не отдать 1R lock. ReduceLong без latch раньше крутил повторный scale на старой книге.

12 Reconcile на каждом тике, до apply

1. vanished longs

Были в RAM, нет на бирже: journal close (один раз, без double-count PnL), кулдаун, снять overlay.

2. orphan TP/SL

Algo/order без позиции — cancel. Иначе утренний стоп открывает SHORT.

3. rogue shorts

Любой SHORT qty>0 — market_close. Стратегия long-only.

4. rearm

Лонг без sized TP/SL — поставить с overlay/journal. 3 фейла или 90 с → fail-closed flatten этого символа.

Поле skip_tick удалено: после reconcile тик стратегии всегда идёт. Раньше зависший orphan-cancel замораживал входы на день.

14 Как это падает в 3AM — и что уже закрыто в коде

Раньше

  • 408 во время backoff стирался из футера → казалось, что «висит»
  • Inflight дропался при «свежей» книге после 502 → второй BUY
  • Panic poller = 30 с «всё ок»
  • size()? в tmux убивал TUI, ордера могли остаться
  • unwrap на UTC/stop — процесс вниз
  • skip_tick после неудачного cancel — день без сделок
  • S4 skip зелёных ≥4% — пустая книга при ленте +7…+131%
  • Journal 644, ключ в ureq Display

Сейчас

  • persist_last_error(..., retry_until, now) держит retry-текст
  • drop_stale_inflight no-op пока backoff
  • take_panics() сразу в last_error
  • size fallback 80×24
  • let Some(sl), UNIX_EPOCH fallback
  • reconcile никогда не глушит tick
  • stretch режет дампы и >35%, не «любой +4%»
  • dir 0700, file 0600, redact, is_safe_order_symbol
Не закрыто полностью (знать оператору): cancel_protectives остаётся best-effort Ok, чтобы flatten всё равно дошёл до market_close. scaled_one_r RAM-only. Нет circuit breaker на всю сессию кроме retry_until. Нет Strategy trait — S4 knobs едут зайцем в MomentumParams.

Монитор — две разные ленты

В ожидании входа = книга стратегии

S4: liquid_universe + s4_setup_skip (те же гейты, что live). Kind: готов / сетап / пауза / блок. Строка «до входа:» — время до окна, % до порога 24h, USDT до VWAP или до отхода от 24h high.

Топ роста / падения = tape

Просто 24h %. Это не список покупок. Тег, только если имя уже в позиции или в wait-книге. Путать их — смотреть «почему не купил лидера дня»: лидер дня часто у high, major, или без отката.
